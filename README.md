# 月光郵局

「月光郵局」是原創的 2–4 人線上推理卡牌遊戲，支援真人玩家與 AI 郵差。玩家依座位顯示為「玩家1」至「玩家4」。

## 遊戲玩法

1. 房主建立郵局，把 6 位數房間代碼分享給朋友。
2. 房主可加入 AI 郵差。至少有 2 位玩家後，房主按「開始送信」。
3. 每輪洗混 16 張牌，每位玩家先拿一張，另有一張牌移出本輪(移出本輪的牌會在必要時使用，詳情查看５號牌規則說明)；輪到你時再抽一張，然後選一張打出。
4. 有目標的牌會先彈出玩家選擇，再彈出行動確認；即使在別人回合，也可以在自己的手牌區查看手牌。出局者不再參與本輪。
5. 郵袋送完時，仍在場且手牌點數最高者獲得月光印記；若只剩一位玩家，該玩家獲得印記。先取得 3 枚印記者獲勝。

### 1–8 點原創卡牌

| 點數 | 卡牌 | 張數 | 效果 |
| --- | --- | ---: | --- |
| 1 | 星門斥候 | 5 | 指定一位對手並猜 2–8 點；猜中使對方本輪出局，不能猜 1 點。 |
| 2 | 幻面觀察者 | 2 | 指定一位對手，私下查看並顯示其手牌；不可告訴其他玩家。 |
| 3 | 銀刃決鬥者 | 2 | 指定一位對手，雙方比較手牌點數；較小者本輪出局，同點則無人出局。 |
| 4 | 靜心守護者 | 2 | 保護自己至下次抽牌前；猜測、決鬥及棄牌攻擊對你無效。 |
| 5 | 秘法師 | 2 | 指定一位玩家（包括自己）棄掉手牌並抽一張新牌；若被迫棄掉 8 點牌，該玩家立即出局；若棄掉手牌時牌庫沒牌則抽取移出本輪的牌。 |
| 6 | 邊境統領 | 1 | 指定一位對手，與其交換手牌。 |
| 7 | 宮廷顧問 | 1 | 抽牌後若兩張手牌中有此牌，且點數總和至少為 12，持有者立即出局。 |
| 8 | 月冠繼承人 | 1 | 棄掉此牌時，持有者立即出局。 |

牌組共 16 張。打出 8 點牌也算棄掉，因此打出者會立即出局。

## Firebase 設定

本遊戲使用同一個 Firebase 專案的匿名登入，房間資料存在 `rooms/moonlit_房間代碼`，和過三關的純數字房間路徑分開。這樣可以沿用過三關已設定的 `/rooms/$roomId` 規則，不需要改動 Firebase Database Rules：

加入房間時也會檢查舊版曾使用的 `rooms/房間代碼` 路徑，因此房主在更新前建立、仍在等待玩家的房間，也能由新版加入。

```json
{
  "rules": {
    "moonlightrooms": {
      "$roomId": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    },
    "siteStats": {
      "gameLinkClicks": {
        ".read": "auth != null",
        ".write": "auth != null && newData.isNumber() && ((!data.exists() && newData.val() == 1) || (data.exists() && newData.val() == data.val() + 1))",
        ".validate": "newData.isNumber()"
      }
    }
  }
}
```

`siteStats/gameLinkClicks` 會累計遊戲頁面載入次數。發布前請在 Firebase Console → **Realtime Database → Rules** 將 `siteStats` 規則合併到現有規則中，不要移除或覆蓋其他專案原有規則。第一次載入時，計數器會建立為 `1`；之後每次頁面載入加 `1`。在 **Realtime Database → Data** 的 `siteStats/gameLinkClicks` 查看數字。

如果你的 `/rooms/$roomId` 規則尚未允許已登入玩家讀寫，請依照上一個過三關專案的 Firebase 設定補上。Firebase Console 還需啟用 **Authentication → Sign-in method → Anonymous**，並建立 **Realtime Database**。此計數器記錄頁面載入，不會辨認真人或阻止訪客重複載入；前端計數不適合作為防作弊或正式流量分析。

以上規則適合原型測試：任何已匿名登入的玩家都可讀寫房間資料。不要把這個資料庫規則當作正式服務的防作弊安全機制。

## 在 VS Code 開啟

1. VS Code 選 **檔案 → 開啟資料夾…**，開啟 `Moonlit Mail` 資料夾。
2. 安裝 VS Code 擴充功能 **Live Server**。
3. 開啟 `index.html`，按右下角 **Go Live**。
4. 分享 Live Server 網址及房間代碼。Live Server 通常只在你的電腦本機可用；若要朋友從外地連線，需部署到公開網頁主機。
